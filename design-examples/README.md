# Design Examples

디자인 시안을 추가하는 공간입니다.

권장 구조:

```text
design-examples/
  homepage/
    hero.md
    service-card.md
  booking/
    booking-flow.md
    empty-state.md
  assets/
    logo/
    treatment/
```

각 예제에는 목적, 상태, 모바일 대응, 필요한 데이터 필드를 기록합니다. 실제 화면 컴포넌트는 `src/`에서 구현하고 이 폴더는 시안과 참고 자료를 보관하는 용도로 사용합니다.
